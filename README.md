# Personal Life Planner

Русский персональный планировщик: задачи на день, привычки и дневник тренировок.
Это готовая статическая Release-PWA на .NET / Blazor WebAssembly, основанная на
[OpenHabitTracker](https://github.com/Jinjinov/OpenHabitTracker) (Jinjinov).

## Запуск GitHub Pages

В репозитории откройте **Settings → Pages**. Выберите **Deploy from a branch**,
ветку **main**, папку **/ (root)** и нажмите **Save**. После успешного развёртывания
ожидаемый адрес: <https://mistershalimoff2016-ux.github.io/personal-life-planner-site/>.
До успешного развёртывания наличие этого адреса в README не подтверждает публикацию.

На iPhone откройте сайт в Safari: **Поделиться → На экран «Домой» → Добавить**.
Дождитесь первой загрузки до отключения сети. Введённые записи сохраняются локально;
этот репозиторий не содержит пользовательской базы. Перед очисткой Safari или
переносом между Safari и установленной PWA экспортируйте JSON/YAML в разделе «Данные».
Фоновые уведомления в веб-версии не обещаются.
