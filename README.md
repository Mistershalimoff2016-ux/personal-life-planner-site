# KOSTYUM — Simple Planner V1

Три раздела: **Сегодня**, **Календарь**, **Спорт**. Настройки и резервная копия —
через шестерёнку. Задача: название → «Добавить»; дата и время необязательны.
Тренировка: дата, тип, минуты → «Сохранить тренировку»; подробности необязательны.
Прежние модели и локальная база IndexedDB сохранены; скрытые данные не удаляются.
Это статическая Release-PWA на .NET / Blazor WebAssembly, основанная на
[OpenHabitTracker](https://github.com/Jinjinov/OpenHabitTracker) (Jinjinov).

Открыть: <https://mistershalimoff2016-ux.github.io/personal-life-planner-site/>.
На iPhone: Safari → **Поделиться → На экран «Домой» → Добавить**.
Первая загрузка требует сети. Обычное обновление выполняется автоматически и не
требует резервной копии или очистки сайта. При несохранённом вводе обновление
откладывается. Перед очисткой браузера или переносом на другое устройство можно
скачать JSON-копию через шестерёнку. Фоновые веб-уведомления не обещаются.

GitHub Pages использует **main**, **/ (root)**. Ветка `simple-planner-candidate`
предназначена для проверки до публикации; она не является источником Pages.
Автоматические браузерные проверки создают изолированные временные профили;
отчёты находятся в ветке `pages-verification`.
